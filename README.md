# Desafío Adopta un perrito

## Cómo ejecutarlo
1. Abre esta carpeta en Visual Studio Code.
2. Abre Terminal > Nueva terminal.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la dirección local indicada por Vite.

Incluye listado de perritos, búsqueda por nombre, filtro por tamaño y un botón
demostrativo para registrar interés en adoptar. No envía solicitudes reales.
Las fotos requieren conexión a internet.

Antes de entregar, revisa este desafío y practica explicar el código.
